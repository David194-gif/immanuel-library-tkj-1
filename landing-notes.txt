1. Memisahkan header dan footer menjadi komponen tersendiri dapat mencegah terjadinya duplikasi kode yang tidak perlu di dalam proyek. Jika terjadi perubahan pada bagian navigasi atau hak cipta di bagian bawah halaman, kita hanya perlu mengubah satu file komponen saja tanpa harus mengedit setiap halaman satu per satu. Ini membuat kode program menjadi jauh lebih rapi, lebih modular, dan jauh lebih mudah untuk dirawat atau dikembangkan dalam jangka panjang. Selain itu, ukuran file utama seperti index.php menjadi lebih ringan sehingga lebih mudah untuk dibaca dan dipahami alur kodenya.

2. Bagian pada halaman-halaman admin yang mengalami masalah duplikasi yang sama adalah komponen struktur tata letak (layout) berupa sidebar dan topbar. Saat ini, kode HTML untuk elemen <aside> (sidebar) dan elemen <header> (topbar admin) ditulis secara berulang dan identik di seluruh halaman manajemen admin. Jika ada perubahan menu navigasi admin atau perubahan format judul halaman, kita harus mengubahnya secara manual di semua file tersebut. Oleh karena itu, bagian sidebar dan topbar ini sangat perlu dipisahkan menjadi komponen tersendiri di dalam folder components/admin/ agar bisa digunakan bersama dengan memanfaatkan fungsi include atau require.
